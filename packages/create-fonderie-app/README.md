# create-fonderie-app

Zero-prompt scaffold for a [Fonderie](https://fonderiejs.com)-powered SaaS backend.

```bash
npx create-fonderie-app my-saas
```

In under 30 seconds you get a working TypeScript Express backend with Fonderie
pre-wired (auth + workspaces), ready to extend with Claude Code:

```bash
cd my-saas
cp .env.example .env
npm run dev
```

Then open Claude Code and say: _"Add billing to this app."_

One command, one golden path — no interactive prompts.
